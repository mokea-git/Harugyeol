하루결 (Harugyeol)

오늘 하루의 결을 읽어드립니다 — AI 일기 + 습관 트래커 + AI 코치 앱

프로젝트 구조

Harugyeol/
├── haru_app/           # Flutter 앱 (iOS / Android)
├── harugyeol-server/   # Fastify 백엔드 API
├── docs/               # 설계 문서
└── assets/             # 공유 디자인 에셋

빠른 시작

Flutter 앱

cd haru_app
flutter pub get
flutter run

백엔드 서버

cd harugyeol-server
npm ci
npm run dev

문서

  • CLAUDE.html — Claude Code 작업 가이드
  • AGENTS.html — 레포지토리 가이드라인
  • docs/harugyeol_context.html — 전체 설계 컨텍스트
